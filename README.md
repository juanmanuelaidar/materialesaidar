# Aidar Materiales — Landing V2

## Estructura

aidar-landing-v2/
├── index.html
├── styles.css
├── script.js
└── assets/
    └── logo-aidar.png

## Personalización

Editar `script.js`:

- whatsappNumber
- phoneNumber
- email
- mapsUrl
- address

## Ejecutar localmente

Opción simple:
- doble clic en `index.html`

Recomendado:
- VS Code + Live Server

También:
python3 -m http.server 8000

Luego abrir:
http://localhost:8000

## Vercel

Se puede subir esta carpeta directamente a Vercel.
